# 需求文档 - 个税计算器

## 1. 背景
需要在当前项目中新增一个页面“个税计算器”，用于帮助用户推算每月的税后收入。

## 2. 功能需求
1. **基础计算**：按照中国大陆最新法规计算个税，默认公积金缴纳比例为12%。
2. **月薪推算**：用户录入税前月薪后，给出1至12月的详细工资推算（包括应发、各项扣除、个税及实发）。
3. **加薪推算功能**：
   - 允许基于当前录入的月薪，再次录入“加薪金额”。
   - 根据加薪后的新月薪，计算出新的工资推算结果。
4. **年终奖计算**：支持录入年终奖金额，一并进行税款和到手收入推算。
5. **UI交互设计**：
   - 功能要求好用，符合人性化。
   - 交互最好是渐进式的（例如：先填月薪看基础推算，然后展开或下一步再提供加薪和年终奖选项）。
6. **访问统计**：页面加载时需要调用后端的IP记录接口。

## 3. 非功能需求
1. **纯前端实现**：所有个税及社保计算逻辑在前端 JavaScript 中实现，无需后端提供计算接口。
2. **入口支持**：支持从现有的系统 homepage 跳转至此页面。
