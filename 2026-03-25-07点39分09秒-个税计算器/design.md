# 设计文档 - 个税计算器

## 1. 架构与技术选型
- **路由设计**：在 `zapp/urls.py` 中增加 `path('tax_calculator', views.tax_calculator, name='tax_calculator')`。
- **视图层**：在 `zapp/views.py` 中增加简单的渲染视图 `tax_calculator(request)`。
- **前端实现**：
  - 新增模板文件：`zapp/templates/zapp/tax_calculator.html`。
  - 使用原生 HTML/CSS 和 Vue 3 (通过 CDN 引入) 来实现渐进式的交互和复杂的动态计算逻辑。这能让计算状态管理（基础月薪、加薪、年终奖）更简洁可靠。
- **系统入口**：在 `zapp/templates/zapp/homepage.html`（Windows 95 风格桌面）中新增一个名为“个税计算器”的应用图标，点击打开新标签页。
- **统计埋点**：页面加载时调用已有的 `POST /apipy/api/pythongetip/` 接口记录访问者 IP。

## 2. 核心计算逻辑设计
按照中国大陆个人所得税法（累计预扣预缴法）设计：
1. **五险一金比例**：
   - 养老保险：8%
   - 医疗保险：2%
   - 失业保险：0.5%
   - 住房公积金：12%（默认设定，不可或可微调）
2. **个税计算公式**：
   - 累计应纳税所得额 = 累计税前收入 - 累计五险一金 - 累计起征点（每月5000元）- 累计专项附加扣除（默认设为0，允许用户修改）。
   - 对应年度综合所得税率表（3% 到 45% 七级累进税率），计算出“累计应纳税额”。
   - 本月应纳税额 = 累计应纳税额 - 已预缴税额。
3. **加薪推算**：
   - 用户可输入“加薪金额”以及“加薪生效月份”。
   - 计算引擎会针对新参数重新跑一遍1-12月的计算模型，与原结果在同一个表格中或者用明显标记显示。
4. **年终奖单独计税**：
   - 计算方法：年终奖金总额 ÷ 12个月，根据其商数查找月度税率表，确定适用税率和速算扣除数。
   - 年终奖应纳税额 = 年终奖金总额 × 适用税率 - 速算扣除数。

## 3. UI 与交互设计 (渐进式)
1. **第一阶段（基础输入）**：
   - 页面居中显示极简表单：“请输入您的税前月薪”，及“公积金比例(12%)”等微调选项。
   - 点击“开始推算”，向下展开1-12月的工资流水明细表。
2. **第二阶段（高阶推算）**：
   - 明细表下方出现两个卡片模块：“🚀 加薪推算” 和 “💰 年终奖推算”。
   - 用户在加薪卡片中填入加薪额度和生效月份，明细表自动刷新，呈现前后对比。
   - 用户在年终奖卡片中填入预期金额，立即计算出年终奖扣税明细及“年度总收入”。
3. **视觉风格**：
   - 页面设计现代化、干净清爽（类似成熟的工具类产品设计），使用卡片式布局和柔和的色彩，以突出数据的可读性。
