# 账号系统设计与实现

## 1. 设计方案

### 1.1 数据库模型
- **使用 Django 内置的 User 模型**：提供账号、密码等基础功能
- **扩展 UserProfile 模型**：用于存储额外信息（手机号、昵称等）
- **字段设计**：
  - User 模型：username（账号）、password（密码）、email（邮箱，可选）
  - UserProfile 模型：user（外键）、phone（手机号）、nickname（昵称）、avatar（头像，可选）

### 1.2 API 接口设计
- **注册接口**：`/apipy/auth/register`（POST）
- **登录接口**：`/apipy/auth/login`（POST）
- **登出接口**：`/apipy/auth/logout`（POST）
- **获取用户信息**：`/apipy/auth/userinfo`（GET）
- **更新用户信息**：`/apipy/auth/update`（POST）
- **修改密码**：`/apipy/auth/changepassword`（POST）

### 1.3 认证方式
- **使用 Django Session 认证**：简单可靠，适合现有项目结构
- **前端存储 sessionid**：通过 cookie 自动管理

### 1.4 前端实现
- **登录页面**：`frontend/src/pages/login/index.tsx`
- **注册页面**：`frontend/src/pages/register/index.tsx`
- **用户信息页面**：`frontend/src/pages/user/index.tsx`（后续扩展）
- **全局状态管理**：使用 React Context 管理用户登录状态

## 2. 实现步骤

### 2.1 后端实现
1. **创建 UserProfile 模型**：在 `zapp/models.py` 中定义
2. **创建认证相关视图**：在 `zapp/views.py` 中添加认证接口
3. **配置 URL 路由**：在 `zapp/urls.py` 中添加认证路由
4. **运行数据库迁移**：生成 UserProfile 表

### 2.2 前端实现
1. **创建登录页面**：实现账号密码登录功能
2. **创建注册页面**：实现账号密码注册功能
3. **添加全局状态管理**：创建 AuthContext 管理登录状态
4. **修改主页面**：添加登录状态显示和跳转链接

### 2.3 安全考虑
1. **密码加密**：使用 Django 内置的密码加密功能
2. **输入验证**：对所有用户输入进行验证
3. **CSRF 保护**：使用 Django 内置的 CSRF 保护
4. **错误处理**：返回友好的错误信息

## 3. 后续扩展

1. **关联手机号**：添加手机验证码功能
2. **昵称设置**：在用户信息页面添加昵称修改功能
3. **头像上传**：支持用户上传头像
4. **第三方登录**：集成微信、QQ等第三方登录
5. **密码找回**：通过邮箱或手机号找回密码

## 4. 技术栈

- **后端**：Django 4.2、SQLite
- **前端**：React、TypeScript、Taro、Sass
- **认证**：Django Session 认证

## 5. 预期效果

- 用户可以通过账号密码注册和登录
- 登录后可以查看和修改个人信息
- 系统支持后续扩展手机号关联等功能
- 安全可靠，密码加密存储
- 前端体验流畅，响应式设计
